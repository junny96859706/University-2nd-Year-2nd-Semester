==================================================
[Eclipse] 코드 복사 시 렉(로딩 지연) 원인 및 해결법
==================================================

1. 원인
  - 이클립스는 코드를 복사할 때 텍스트뿐만 아니라 
    색상, 폰트 등 서식 정보(HTML/RTF)를 함께 클립보드에 저장함.
  - 이를 웹 입력창에 붙여넣을 때 브라우저가 서식을 해석하느라 
    로딩 지연(렉)이 발생함.

2. 해결 방법 (가장 빠르고 확실한 방법)
  - 붙여넣기 할 때 [ Ctrl + Shift + V ] 단축키 사용
  - 서식(Style)을 모두 제거하고 순수 텍스트만 0.1초 만에 붙여넣어짐.


==================================================
[Java] 기본 타입 vs 참조 타입의 메모리 동작 요약
==================================================

1. 기본 타입 (Primitive Type)
  - 종류: int, double, boolean, char 등
  - 저장 위치: 스택(Stack) 영역
  - 동작 방식:
    * 변수 공간에 '실제 데이터 값'이 직접 저장됨.
    * 예) int i = 3; 후 i = 0; 실행 시
      -> 힙(Heap) 영역은 전혀 사용하지 않음.
      -> 스택 영역의 'i' 변수 상자 안의 값이 3에서 0으로 직접 덮어씌워짐.

2. 참조 타입 (Reference Type)
  - 종류: 배열(Array), 클래스(Class), 인터페이스 등
  - 저장 위치: 
    * 스택(Stack): 객체의 메모리 주소값(레퍼런스) 저장
    * 힙(Heap): 실제 객체 데이터 저장
  - 동작 방식:
    * new 연산자로 힙 영역에 객체를 새로 생성하고, 스택 변수에는 그 주소만 저장함.
    * 예) int[] arr = new int[3]; 후 arr = new int[5]; 실행 시
      -> 힙 영역에 크기 5짜리 새로운 배열 객체 생성
      -> 스택의 arr 변수가 가리키는 주소값이 새 객체의 주소로 교체됨.
