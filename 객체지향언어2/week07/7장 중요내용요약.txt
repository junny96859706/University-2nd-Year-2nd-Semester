1. 컬렉션 프레임워크 (Collection Framework)
--------------------------------------------------
 - 가변 크기의 객체들을 효율적으로 다루기 위한 자바 표준 구조.
 - 기본 타입(int, double 등)은 직접 저장 못함 -> Wrapper 클래스로 포장하여 저장.
 - 주요 인터페이스/클래스:
   * List 계열 (ArrayList, Vector): 순서 있음, 중복 허용, 인덱스로 접근.
   * Set 계열 (HashSet): 순서 없음, 중복 허용 안 함.
   * Map 계열 (HashMap): Key-Value 쌍으로 관리, Key는 중복 불가.


2. ArrayList & Vector
--------------------------------------------------
 - 배열과 달리 크기가 동적으로 조절되는 가변 배열.
 - 주요 메서드: add(), get(index), remove(index), size(), clear()
 - Vector는 동기화(Thread-safe)를 지원하지만, 단일 스레드에서는 ArrayList를 주로 사용.


3. HashMap<K, V>
--------------------------------------------------
 - 키(Key)와 값(Value)의 쌍으로 데이터를 저장.
 - 주요 메서드: put(key, value), get(key), remove(key), keySet()
 - 검색 속도가 매우 빠름.


4. 제네릭 (Generics)
--------------------------------------------------
 - 클래스나 메서드에서 사용할 데이터 타입을 파라미터 형태로 지정하는 기능. (예: <T>, <E>)
 - 장점: 
   1) 컴파일 시점에 강력한 타입 체크 가능 (잘못된 타입 저장 방지).
   2) 객체를 꺼내 쓸 때 불필요한 다운캐스팅((String) 등)을 생략 가능.
