#3장: 반복문과 배열 그리고 예외처리

3.1 반복문
-for문: 반복 횟수가 정해져 있을 때 사용 (for(초기문; 조건식; 반복후작업))
-while문: 조건식이 참인 동안 계속 반복
-do-while문: 무조건 최소 1번은 실행한 후 조건을 검사


3.2 continue 문과 break 문
-continue: 현재 반복의 남은 코드를 스킵하고 다음 반복으로 바로 진행
-break: 자신을 감싸고 있는 가장 가까운 반복문을 즉시 탈출 //하나의 반복문만 벗어난다!!


3.3 배열
개념: 같은 타입의 데이터들을 연속된 공간에 저장하는 자료구조
선언 및 생성: int[] arr = new int[5]; (생성 시 크기 고정, arr.length로 크기 확인)
-for-each문 (향상된 for문): for (int num : arr) 형태로 배열 요소를 순회
-array.lenth 필드를 사용하면 배열의 크기를 알수있다!!

(※ 자바도 C/C++ 출신 개발자들을 위해 int arr[]; 형태를 문법적으로 지원하지만, int[] arr;을 정석으로 권장)


3.4 다차원 배열
-2차원 배열: 행과 열로 이루어진 배열 (int[][] arr = new int[2][3];)
-비정방형 배열: 각 행마다 열의 크기가 다른 배열도 생성 가능

-score.length : 전체행의 개수
-score[ti].length : i번 행의 열개수


3.5 메소드에서 배열 리턴
-메소드에서 어떤 배열이든지 리턴하면, 배열공간 전체가 아니라 배열에 대한 레퍼런스만 리턴된다
(배열안의 데이터전체를 짐싸서 들고 돌아오는게 아니라 힙 영역에 있는 배열의 주소표만 달랑 들고 리턴)

- = 메소드에서 배열을 리턴할 때는 배열 레퍼런스(참조값/주소)만 전달됨
-리턴 타입 명시 예시: public static int[] makeArray() { ... }


3.6 main() 메소드
public static void main(String[] args)의 args는 명령행 인자(Command Line Arguments) 배열
콘솔에서 프로그램을 실행할 때 전달한 문자열 값들이 들어옴!!!!


3.7 자바의 예외 처리 (try-catch-finally)   
예외(Exception): 프로그램 실행 중 발생하는 오류 (예: 0으로 나누기, 배열 인덱스 초과 등)
구조:try { ... }: 예외가 발생할 가능성이 있는 코드
catch (예외클래스 e) { ... }: 예외 발생 시 처리할 코드
finally { ... }: 예외 발생 여부와 상관없이 무조건 실행되는 코드
-모든 예외 클래스를 import해야 하는 것은 아니며, 어느 패키지에 속해 있느냐에 따라 import문 필요 여부가 갈림

#예외(Exception)도 힙(Heap)에 생성되는 '객체'다!!!
자바에서 프로그램 실행 중 오류가 발생하면, JVM은 오류 정보가 담긴 예외 클래스의 객체를 힙 영역에 new 생성한 뒤 실행 흐름에 던집니다.

예: new ArithmeticException("0으로 나눌 수 없음")

//try-catch-finally기본동작 코드 예시

try {
    // 예외가 발생할 가능성이 있는 코드
    int result = 10 / 0; // ArithmeticException 발생!
} catch (ArithmeticException e) {
    // e는 힙에 생성된 예외 객체의 주소값(레퍼런스)을 받음!
    System.out.println("0으로 나눌 수 없습니다: " + e.getMessage());
} finally {
    // 예외 발생 여부와 상관없이 무조건 실행되는 블록 (자원 해제 등)
}

#문자열비교
-문자열비교할때 (==)연산자를 쓰면 안된다!!!
(두 문자열의 내용이 같은지가 아니라,메모리주소가 같은지를 비교한다)

- .equals()메소드: 문자열의 실제내용(글자)가 같은지를 비교한다.
( 예시: if (text.equals("exit"))  )
-대소문자 구분 없이 비교하고 싶다면: "exit".equalsIgnoreCase(text) 사용

+  [Java] 열거형 (enum, Enumeration) 핵심 요약

1. 개념
  - 서로 관련 있는 상수들의 집합을 정의하는 특별한 데이터 타입
  - 요일, 계절, 상태값 등 정해진 범위의 값만 다룰 때 사용

2. 기본 문법 및 사용법
  public enum Week {
      MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
  }

  Week today = Week.FRIDAY; //정의된 각각의 상수는 week클래스의 하나의 객체이다!

3. 왜 쓰는가? (장점)
  - 타입 안전성: 정해진 상수 외의 잘못된 값 입력을 컴파일 시점에 차단
  - 가독성: 숫자(1, 2) 대신 직관적인 이름(SPRING, SUMMER) 사용
  - switch문 활용: switch(today) { case FRIDAY: ... } 형태로 깔끔하게 사용 가능

4. 핵심 특징 (자바 enum의 차별점)
  - 단순 숫자가 아니라 '클래스(Class)' 기반임
  - 각 상수는 힙(Heap) 영역에 생성되는 '객체(Object)'
  - 필드, 생성자, 메소드를 내부에 추가하여 확장 가능

5. 자주 쓰이는 내장 메소드
  - values() : 모든 enum 상수를 배열로 반환 (for-each문과 자주 사용)
  - valueOf("상수명") : 문자열과 일치하는 enum 객체 반환
