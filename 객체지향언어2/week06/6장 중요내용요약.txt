1. 패키지(Package)와 import
--------------------------------------------------
 - 패키지: 관련 클래스들을 하나로 묶어 관리하는 폴더(디렉터리) 개념.
 - 역할: 클래스 이름 충돌 방지, 접근 권한 관리, 코드 재사용성 향상.
 - import: 다른 패키지에 선언된 클래스를 가져와 사용할 때 선언.
   (java.lang 패키지는 기본 패키지이므로 import 없이 자동 사용 가능)


2. 모듈(Module)
--------------------------------------------------
 - Java 9부터 도입된 개념으로, 여러 패키지와 관련 리소스를 하나로 묶은 단위.
 - 패키지들의 집합체로서 모듈 간의 의존성을 명확하게 관리 가능.


3. Object 클래스 (최상위 클래스)
--------------------------------------------------
 - 자바의 모든 클래스는 직/간접적으로 Object 클래스를 상속받음.
 - 주요 메서드:
   * toString() : 객체의 문자열 표현 리턴 (기본: 클래스명@해시코드)
   * equals(Object obj) : 객체의 참조 값이 같은지 비교 (오버라이딩하여 내용 비교 가능)
   * hashCode() : 객체를 식별할 고유 해시코드 값 리턴


4. Wrapper 클래스 (포장 클래스)
--------------------------------------------------
 - 기본 타입(int, char, double 등)을 객체로 다루기 위해 사용하는 클래스.
   (Integer, Character, Double 등)
 - 박싱(Boxing) : 기본 타입 -> Wrapper 객체 변환
 - 언박싱(Unboxing) : Wrapper 객체 -> 기본 타입 변환
 - 자바는 오토 박싱/언박싱을 자동으로 지원함.


5. 문자열 처리 클래스 3대장
--------------------------------------------------
 - String: 불변(Immutable) 객체. 문자열 수정 시 새로운 객체가 생성됨.
 - StringBuffer: 가변(Mutable) 객체. 동기화를 지원하여 멀티스레드 환경에서 안전함.
 - StringBuilder: 가변(Mutable) 객체. 동기화를 지원하지 않으나 단일 스레드에서 속도가 빠름.
 - StringTokenizer: 특정 구분자(delimiter)를 기준으로 문자열을 분할하는 유틸리티.


6. Math & Calendar 클래스
--------------------------------------------------
 - Math: 수학 계산 관련 static 메서드 제공 (abs, max, min, sqrt, random 등).
 - Calendar: 날짜와 시간 정보를 다루는 추상 클래스 (getInstance()로 객체 생성).
