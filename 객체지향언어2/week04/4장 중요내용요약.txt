[자바 4장 : 클래스와 객체 핵심 요약 노트]

1. 객체 지향 프로그래밍 (OOP) 기본
  - 클래스(Class) : 객체를 만들기 위한 틀 (설계도)
  - 객체(Object) / 인스턴스(Instance) : 클래스로부터 생성된 실체 (메모리에 할당됨)

2. 자바 클래스 만들기 및 객체 생성
  - 클래스 구성 요소  = 멤버 : 필드(변수), 메서드(함수)
  - 객체 생성 문법 :
      클래스명 변수명 = new 클래스명();
      (예: Circle pizza = new Circle();)

-레퍼런스변수: 객체의 실제 데이터(값)을 직접 갖고 있는것이 아니라, 그데이터가 저장된 메모리의 주소(위치)를 가리키고 있는 변수 (개념적으로 포인터!!!)


3. 생성자 (Constructor)
  - 역할 : 객체가 생성될 때 초기값을 설정하는 특별한 메서드
  - 특징 :
      ① 클래스 이름과 완전히 동일해야 함
      ② 반환 타입(return type)을 적지 않음 (void도 안 씀)
      ③ 객체 생성 시(`new`) 딱 한 번만 자동 호출됨
  - 기본 생성자(Default Constructor) : 생성자를 안 만들면 자바가 매개변수 없는 기본 생성자를 자동으로 제공함.
  - this 키워드 : 현재 객체 자신을 가리키는 참조 변수 (필드명과 매개변수명이 같을 때 구분용)
	(또 메소드가 객체자신의 레퍼런스를 리턴해야 하는 경우에도 this를 리턴하면 된다)

  - this() : 같은 클래스 내의 다른 생성자를 호출할 때 사용 (반드시 생성자 첫 줄에 위치)


4. 객체 배열 (Array of Objects)
  - 객체 참조 변수들의 배열 생성 -> 각 요소마다 객체를 new로 개별 생성해야 함!
  - 2단계 생성 방식 :
      Circle[] c = new Circle[3]; // 1. 참조 배열 공간만 생성
      for(int i=0; i<c.length; i++) {
          c[i] = new Circle();    // 2. 실제 객체 생성 후 연결
      }


5. 메서드 활용 및 오버로딩
  - 인자 전달 방식 : 
      ① 기본 타입(int, double 등) : 값 복사 (Call by Value) -> 원본 안 바뀜
      ② 객체/배열 : 참조(주소) 복사 (Call by Reference) -> 원본 내용 변경됨
  - 메서드 오버로딩 (Overloading) :
      한 클래스 내에 이름은 같지만 '매개변수의 개수나 타입'이 다른 메서드를 여러 개 정의하는 것


6. 가비지 컬렉션 (Garbage Collection)
  - 자바 가상 기계(JVM)가 더 이상 어디서도 참조하지 않는 객체(쓰레기 메모리)를 자동으로 수거함
  - 가비지 만들기 : 객체 참조 변수에 null 대입 (예: pizza = null;)

- System.gc(); //가비지 컬렉션 강제 요청!!!



7. 접근 지정자 (Access Modifier)
  - private : 같은 클래스 내부에서만 접근 가능 (캡슐화, 데이터 보호)
  - default (생략시) : 같은 패키지 내부에서만 접근 가능
  - protected : 같은 패키지 + 상속받은 자식 클래스에서 접근 가능
  - public : 패키지 제한 없이 어디서나 접근 가능


8. static 멤버 vs non-static 멤버
  - non-static (인스턴스 멤버) : 객체마다 따로 생김, 객체 생성(`new`) 후 사용 가능
  - static (클래스 멤버) :
      ① 객체를 생성하지 않아도 프로그램 시작 시 메모리에 단 하나만 생성됨
      ② 모든 객체가 하나의 변수를 '공유'함
      ③ 사용법 : 클래스명.static멤버 (예: Math.abs(), System.out)
		(클래스 이름으로 바로 접근할수 있다)
      ④ static 메서드는 내부에 non-static 필드/메서드나 this를 직접 사용할 수 없음!

(static메소드는, 객체 없이도 존재하기 때문에, 객체와 함께 생성되는 non-static멤버를 사용할수 없고 static멤버들만 사용 가능하다!!!)

9. final 키워드
  - final 변수 : 변경할 수 없는 '상수'가 됨 (선언 시 초기화 필수, 관례상 대문자로 작성)
  - final 메서드 : 오버라이딩 불가
  - final 클래스 : 상속 불가
