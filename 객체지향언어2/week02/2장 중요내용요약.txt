-1. 자바 vs 파이썬 출력 방식 차이 (★가장 헷갈렸던 부분)
쉼표(,) 사용 금지
파이썬: print("이름:", name) ⭕ (자동 공백 추가)
자바: System.out.println("이름:", name); ❌ 컴파일 에러!
+ 연산자로 연결자바 println 안에서는 무조건 + 연산자로 이어붙여서 문자열 1개로 만들어줘야 함
예시: System.out.println("이름: " + name + " 나이: " + age);

2. 콘솔 출력 메소드 3대장
print(): 줄바꿈 없이 출력
println(): 출력 후 자동 줄바꿈
printf(): 포맷 서식 지정 출력 (자동 줄바꿈 안 되므로 끝에 \n 필수)   
%d: 정수%.6f: 소수점 6자리 실수 (예: 2.145000)   %s: 문자열
⚠️ 주의: println("%d", a)처럼 println에 포맷 지정자를 넣으면 컴파일 에러! 
포맷 지정은 무조건 **printf*

3. var란?
변수의 타입을 개발자가 직접 명시하지 않고, 초기화하는 값을 통해 컴파일러가 타입을 자동으로 추론하게 만드는 키워드.
(특징:타입 변경 불가: 한번 타입이 결정되면 다른 타입의 값을 넣을 수 없다.

8.switch문암기
switch(식){
	case 값1:
		실행문;
		break;

	case 값2:
		실행문;
		break;

	default:  //default는 "조건이 모두 맞지 않을 때 실행되는 예외/기본 처리 구문".
		실행문장 n;
		break; //맨마지막에 default를 배치할때는 생략가능!

}

9.컴퓨터 내부의 Scanner시스템 동작 원리

-숫자 int로 2진수를 그냥 받으면 '10진수 천십'이 되어버린다
-이진수를 입력받으려면 문자열 형태로 입력받은후 이진수로 변환한다!
  (String str = scanner.next();   -> byte status = Byte.parseByte(str,2); )

-📌 딱 하나 주의할 예외 케이스 (시험/실습용)
byte 타입의 범위는 -128 ~ 127이다.
만약 테스트 입력으로 맨 앞 비트(최상위 비트)가 1인 8자리 이진수(예: 10000011)를 넣으면 Byte.parseByte() 시 131로 계산되어 byte 범위를 초과하므로 NumberFormatException 에러가 터질 수 있다.
